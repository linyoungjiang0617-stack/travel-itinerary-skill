# 旅行手账与路线图 · Travel Itinerary Skill

一个面向 Codex 的旅行规划 Skill：把目的地、航班、住宿和个人偏好整理成顺路行程，并指导生成适合手机的共享旅行网页和简洁路线图片。

![旅行手账工作流程](docs/workflow.svg)

## 亮点

- **路线优先**：结合住宿、交通和体力安排，减少折返；为主要节点估算步行和耗时。
- **靠谱的信息**：核对景点、门店、营业时间和交通，记录来源与核验日期；不确定的项目明确标注。
- **可共享的旅行手账**：指导生成手机网页，支持打卡、弹性顺延、固定航班冲突提醒和两设备同步。
- **预算和导航**：记录预计与实际支出、计算人均，并为地点和餐饮提供地图入口及微信备用方式。
- **一眼看清行程**：从最终计划生成可保存的路线图图片；必要时另输出 PDF。

> 这是指导 AI 助手完成工作的 **Skill 指令包**，不是开箱即用的网站程序，也不包含实时数据或 AI 服务。网站、同步和实际访问能力取决于执行环境和部署平台。

## 安装与使用

将仓库中的 `travel-itinerary` 文件夹复制到 `~/.codex/skills/travel-itinerary`，然后在 Codex 中输入：

```text
使用 $travel-itinerary，帮我规划一次旅行：出发地、目的地、日期、人数和已订航班酒店如下……
```

也可以描述旅行需求，让助手按适用情况选择 Skill。提供酒店位置、预算、体力和饮食偏好，有助于规划得更顺路。

## 如何工作

1. 整理旅行约束，核验最新资料。
2. 安排逐日路线、餐饮、交通、住宿和预算。
3. 按需求生成或更新共享网站，并保留已确认的数据。
4. 生成简洁路线图片，验证时间、导航、同步与排版。

## 使用边界

- 门店、航班、价格、天气和交通可能变化，出发前应再次核实；没有可靠证据时会标为待确认。
- 网页公开范围由使用者决定；拿到可编辑链接的人可能修改共享行程。
- 微信内能否直接唤起地图、以及中国大陆网络的可访问性取决于设备和托管条件，须实际测试。
- 路线图片是生成时的快照，网页发生变化后需重新生成。
- 不提供网站源代码模板或免费的托管、域名和数据库；需要可用的构建及部署环境。
